将世界主流的开源定向越野制图工具 OpenOrienteering Mapper 完整移植至 iPad 与 iPhone。为野外踏勘、GPS 轨迹绘制与多设备协同而生。

Universal 跨端适配

适配 iPad 全系列大屏（支持 Apple Pencil 绘制）与 iPhone 全系列（大屏 Pro Max 到小屏 mini 随身查图）。

🌲

离线外业就绪 (Offline Ready)

支持 GeoTIFF 航片大底图脱网读取，并在深山无信号环境中结合 GPS 与电子罗盘进行实时轨迹定位。

☁️

iCloud 就地读写与多机协同

支持 iOS 系统“文件”App 原地保存，Mac、iPad、iPhone 间无缝同步，并支持分测区导入合并总图。

🔄

GitHub Actions 自动同步

每日自动检测 upstream 官方主线提交，完成无冲突合并与 Apple Silicon 云端编译健康检查。

Release Notes

版本更新历史

持续跟进官方主线演进，记录每一次功能改进、缺陷修复与平台优化。

v0.9.7-ios.3 最新版本
2026 年 10 月 6 日
  • 新功能 iPhone Universal 架构全面适配：调整打包配置中的 UIDeviceFamily 为 [1, 2]，iPhone 13/14/15/16 全机型原生支持。
  • 优化 移动端首页按钮精简：合并冗余的「导入项目」与「打开地图」按钮为统一的 Open map ...，并在打开文件时自动识别 .mapperproject 目录包与工程清单。
  • CI/CD 集成 GitHub Actions 自动化同步流水线：每日凌晨自动拉取 OpenOrienteering/mapper 官方 master 提交，执行无冲突合并及 C++ 依赖编译验证，遇异常自动提 Issue 报警。
  • 修复 修复底图相对路径与离线状态判定：完善底图缺失检测，准确呈现 offline ready / location not set / files missing 测绘就绪状态。
v0.9.7-ios.2
2026 年 9 月
  • 优化 Apple Silicon 与 Xcode 工具链重构：支持基于 CMake 与 Ninja 的纯原生 arm64 架构打包。
  • 新功能 CoreLocation 与 CoreMotion 原生传感器桥接：实现平板上的 GPS 实时坐标显示与指北针指南针自动回正。
  • 新功能 LSSupportsOpeningDocumentsInPlace 就地读写支持：开启 iOS 文件提供者原地修改能力，支持配合 iCloud 云盘实现实时多端同步。
v0.9.7-ios.1
2026 年 8 月
  • 里程碑 首个 iPadOS 原生编译版本问世：完成 Qt 6.11.1 静态构建并在真实 iPad 设备上成功点亮运行。
  • 新功能 移动端 GDAL / PROJ 交叉编译集成：支持读取 GeoTIFF 高清卫星遥感与航拍正射底图。
  • 新功能 触控手势模式移植：支持移动端触控优化（长按、单指平移、双指缩放及触摸屏大按钮菜单）。
