Release Notes

Version History

Continuously tracking upstream development with feature enhancements, performance optimizations, and platform improvements.

v0.9.7-ios.3 Latest
October 6, 2026
  • Feature Universal iPhone Architecture Support: Configured UIDeviceFamily to Universal [1, 2], enabling full native compatibility with all iPhone 13/14/15/16 models.
  • Optimization Streamlined Mobile Home Screen: Consolidated redundant Import/Open buttons into a single "Open map ...", automatically recognizing .mapperproject packages and project manifests.
  • CI/CD Automated Upstream Sync Pipeline: Integrated daily GitHub Actions workflow to fetch OpenOrienteering/mapper master, perform merges, verify C++ compilation, and alert via Issues on conflict.
  • Fix Relative Basemap Paths & Readiness Check: Fixed relative template path resolving and refined project inspection to accurately report "offline ready", "location not set", and "files missing".
v0.9.7-ios.2
September 2026
  • Optimization Apple Silicon & Toolchain Modernization: Migrated to native CMake and Ninja toolchain with pure arm64 device packaging.
  • Feature CoreLocation & CoreMotion Native Integration: Enabled real-time GPS coordinate plotting and digital compass rotation on mobile devices.
  • Feature In-Place Document Editing (LSSupportsOpeningDocumentsInPlace): Enabled direct read/write from iCloud Drive without copying into isolated sandboxes.
v0.9.7-ios.1
August 2026
  • Milestone First Native iPadOS Port Bootstrapped: Successfully compiled and launched on physical iPad hardware using static Qt 6.11.1.
  • Feature Mobile GDAL & PROJ Geospatial Engine Cross-Compilation: Supported high-resolution GeoTIFF aerial imagery and coordinate reference system transformations.
  • Feature Touch Gesture Interface: Optimized touch interactions including pinch-to-zoom, pan gestures, and touch toolbar sizing.
